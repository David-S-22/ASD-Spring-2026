1. Contradiction. Does the finding state the opposite of a value in the
   evidence? Quote the evidence value and the finding's version of it.
2. Invention. Does it name any service, file, route, number, job or dependency

3. Echo. Does it report something as a problem only because the question asked

4. Self-contradiction. Does it place the same item in two categories that
   cannot both be true?
5. Omission. Is there something in the evidence a marker would care about that
   the finding missed?
6. Verdict: keep, correct, or drop, and one sentence saying why.

sentence rather than padding.
